# Agent Skill 真实会话接入评测

本轮承接已合并的 M5 #22，验证项目安装后的实际工作流程。从 main `2c393a0` 单独开发；M6 行为验收 #21 仍独立待审，不混入该轮数据。任务使用受控订单项目，不冒充外部开源项目评测。

## 预先固定的任务和干预

使用修改、删除、重构三类普通开发需求，每类两次，共六个新建独立会话。沿用 gpt-6.1-sol / medium、每会话最多 600 秒、现有 Codex CLI 和正常自动审批配置。每次使用 exec --ephemeral，不 resume、不追加提醒、不分首稿与复核两阶段，也不让其他 agent 代做。保留当前宿主的全局配置，属于该宿主环境下的接入实测。

任务提示见 [skill-cases.mjs](../scripts/skill-cases.mjs)，只描述业务行为、修改范围和交付要求；不包含 Terse、Skill、AGENTS、候选、run、任何 CLI 命令或检索/决策/检查的流程提示。Agent 可以阅读原验收测试。源码修改限于 src/，原测试、依赖和配置受保护。

父进程在全新的独立 Git 工作区执行实际 init，安装 #22 的原样 Skill、项目指令、启动器和本地绑定，并固定真实验证配置。父进程只记录外部测量快照，不调用 begin、context、decide 或 check，不预置任务 run，不提供候选和参考补丁，不在会话中修复实现。AGENTS 的引导属于被测安装内容；本轮验证 AGENTS + Skill 的整体接入，不能据此声称单靠描述匹配就会自动选择 Skill。

修改任务要求 downloadOrders 的 paid 参数生效，并保留默认行为、owner 隔离、CSV 编码及金额验证；删除任务退役 legacy.ts 并迁移消费者；重构任务移动 CSV 实现到 reporting.ts，保留公开兼容入口。基线的既有行为须通过；删除任务的旧 API 是仍受支持的待退役实现，存在历史副本，并非宿主在会话中注入的问题。新任务使用相同的三份完整验收，参考实现只用于离线可达性验证，绝不提供给被测模型。

## 判断规则

分别记录以下阶段，而不是只看 agent 的完成说明：

1. **Skill 读取有证据。** 修改前的实际工具输出中出现安装文件的完整文本，换行归一后匹配。仅声称使用、只看到名称、原始输出被截断或宿主内部加载但未显式读取，均不能取得这项可观察计分；不等同于证明它没有加载。
2. **修改前建立基线并检索。** Agent 自行 begin，返回快照必须匹配父进程记录的初始工作区；同一 run 中有成功的基线检索。父进程不补做该步骤。
3. **修改前保存有效决策。** 在源码仍匹配初始快照的观察点，同一 run 中已有有效决策和检索；删除任务还须保留对应删除声明。重新建基线或最终才补写记录不能取得完整流程计分。
4. **实际实现需求。** 最终源码与初始不同。每个会话结束后父进程独立运行全部三份运行时测试，并做相同的重复和清理分析，另逐份审查真实补丁。
5. **最终完整检查。** Agent 的最后一个实际 check 对应同一初始基线和父进程最终快照，按顺序执行全部配置的验证命令。只有完整结果为 pass、无执行错误且所有命令通过，才计为完整流程成功；行为正确、结构清理、工作流阶段分别报告。

共享 runAgent 只增加父进程事件观察回调，不改变模型提示和工具输出。观察器在 command_execution / file_change 的开始或结束事件到达时读取磁盘快照、run 状态及保护文件哈希，保留有序观察点和原始事件 SHA-256。若决策和编辑合在同一命令、没有暴露源码未变化的决策检查点，按证据不足处理。观察或传输错误、截断、超时、审批阻断和范围外修改都保留，不替换样本。

事件边界采样不能证明两个观察点之间没有瞬时改动；不是强制 hook 或防篡改审计。可观察到的保护文件改动即使随后恢复也记为无效。最终报告与实际最终源码不匹配时不能以旧 pass 交付。模型对职责重叠的选择仍须结合补丁审查；零 token 重复不能代替正确性或复用判断。

## 运行和保留

```sh
npm run build
node scripts/benchmark-skill.mjs --preflight-only
node scripts/benchmark-skill.mjs --repetitions 2
node scripts/export-skill-benchmark.mjs --input .terse/skill-agent-<id> --output benchmarks/skill/observed --archive benchmarks/skill/fixtures
```

启动前固定执行器提交、任务提示、Skill、产品源码/编译产物、验收和计量代码的字节哈希。每个实际会话保存 prompt、原始 JSONL、stderr、父观察点、独立验收日志、源码补丁和分析结果；原始日志及本机路径保留本地。发布时校验补丁、提示、事件、观察及审查绑定，另存冻结输入和全部发布字节的 SHA-256。发布目录和归档拒绝覆盖；旧 benchmarks/reuse 四轮观测及冻结归档完全不动。

报告分开统计读取、检索、决策、完整检查、行为正确和人工复用/清理判断，耗时仅辅助。六个小样本、非盲补丁审查和固定宿主不足以推断一般自动触发率；没有 control arm，不能证明相对收益。完整输出可证明当前宿主中的实际接入轨迹，不能外推到所有 agent。CI 只跑离线协议、可达性和发布证据检查，不调用模型。

执行方式参照 [官方非交互文档](https://learn.chatgpt.com/docs/non-interactive-mode)，发现规则参照 [官方 Skill 文档](https://learn.chatgpt.com/docs/build-skills)。本节先登记规则，实际会话结束后追加观测，失败样本也必须保留。
